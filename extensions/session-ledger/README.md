# session-ledger

Расходы и активность по всем сессиям pi на машине: стоимость, токены, доля кэша, вызовы и ошибки инструментов, компакции. Группировка по проектам, моделям, дням, инструментам и отдельным сессиям.

Читает `~/.pi/agent/sessions/**/*.jsonl` (или `$PI_CODING_AGENT_DIR/sessions`). Ничего не пишет.

## Команда в pi

```
/stats                          последние 7 дней по проектам
/stats today model              сегодня по моделям
/stats all tool                 ошибки инструментов за всё время
/stats 30d session mediahub     сессии проекта mediahub за месяц
```

Аргументы в любом порядке: период `today | yesterday | 7d | 30d | all`, группа `project | model | day | tool | session`, любое другое слово это подстрока имени проекта или пути cwd.

Клавиши в отчёте: стрелки, PgUp, PgDn, Home, End, `r` пересчитать, `q` или Esc закрыть.

В разрезе по сессиям (`/stats ... session`) под каждой строкой отдельной строкой показаны имя сессии или первый промпт. В строке Totals учитываются также итоги веток (`branch summary`, суммы при `/fork` и `/tree` с суммаризацией).

## CLI без pi

```bash
node extensions/session-ledger/cli.ts                 # 7d по проектам
node extensions/session-ledger/cli.ts all model
node extensions/session-ledger/cli.ts 30d tool --json
node extensions/session-ledger/cli.ts --dir /path/to/sessions
```

Требует Node 22.18 или новее, зависимостей нет.

## Что показывает

| Колонка | Смысл |
|---|---|
| sess | сессий, затронувших группу |
| turns | ответов модели |
| in | некэшированные входные токены |
| cache, cache% | прочитано из кэша и доля от всего промпта |
| out | выходные токены |
| cost | сумма `usage.cost.total` по ответам и компакциям |
| tools, err% | вызовов инструментов и доля результатов с `isError` |
| compact | компакций |

## Оговорки

- Стоимость берётся из pi. Модели без прайса в каталоге дают `$0`, при этом токены считаются.
- Сессия входит в период, если хотя бы одна её запись сделана в этом периоде. Группировка по дням точная, остальные группы считают сессию целиком.
- Считаются все записи файла, включая заброшенные ветки `/tree`: деньги за них тоже уплачены.
- Ошибки инструментов относятся к модели, отвечавшей последней в этой сессии на момент вызова.
